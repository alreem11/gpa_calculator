# GPA Calculator

A simple GPA Calculator project developed using Python. The system allows users to enter course grades and credits, then calculates the GPA and displays the final result.

## Features
- Enter course grades
- Enter course credits
- Calculate GPA
- Display academic message based on GPA

## Technologies Used
- Python
- Tkinter

## Files
- `gpa_gui.py`: contains the graphical user interface
- `gpa_calculate.py`: contains the GPA calculation logic

## How to Run
1. Download the project
2. Open the project folder
3. Run the GUI file

```bash
python gpa_gui.py
